# Поиск фото по образцу

Приложение для macOS: находит в папках снимки, похожие на образец. Показывает копии в другом размере и формате, обработанные и кадрированные версии, а также просто похожие кадры. Всё работает локально, фото никуда не отправляются.

Нужны macOS 14 и Apple Silicon. Сборка: `./build.sh` (достаточно Command Line Tools: `xcode-select --install`). Приложение: `PhotoFinder.app`.

- Образец можно перетащить в окно, выбрать (⌘O) или вставить из буфера (⌘V). Образцов может быть несколько: ищутся фото, похожие на любой из них.
- Папки для поиска: ⇧⌘O или перетаскиванием.
- Порог схожести можно менять после поиска, результаты обновляются сразу.
- Понимает RAW. Сравнение идёт параллельно на всех ядрах через «отпечатки» Vision.
- Отпечатки кэшируются на диске, поэтому повторный поиск по тем же папкам проходит быстро.
